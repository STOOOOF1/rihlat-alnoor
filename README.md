# رحلة النور — أركان الإسلام والإيمان

لعبة تعليمية ثلاثية الأبعاد للأطفال: يتجوّل الطفل في جزيرة مفتوحة، ويُكمل ١١ مرحلة تعلّمه أركان الإسلام الخمسة وأركان الإيمان الستة، بثلاثة مستويات صعوبة (٥–٧ سنوات، ٨–١٠ سنوات، ١١ سنة فأكثر).

## التشغيل
افتح الملف `index.html` بنقرة مزدوجة (Chrome أو Edge). لا يحتاج إنترنت ولا تثبيت.

## التحكم
- الحاسوب: الأسهم أو WASD للمشي، Shift للركض، المسافة للقفز، E للتفاعل، اسحب الفأرة لتدوير الكاميرا، M الخريطة، J كتاب المعرفة، Esc القائمة.
- الهاتف واللوحي: عصا تحكّم يسار الشاشة، واسحب يمينها للكاميرا، وأزرار للقفز والتفاعل والركض.
- يدعم ذراع التحكم (Gamepad).

## المراحل
| # | المرحلة | المكان | النشاط |
|---|---|---|---|
| ١ | الشهادتان | قمة التوحيد | جمع كلمات الشهادة بالترتيب وإضاءة المنارة |
| ٢ | الصلاة | قرية المسجد | ترتيب الوضوء، ثم السماء تتغيّر والطفل يركض لبوابة الصلاة الصحيحة، وعدد الركعات |
| ٣ | الزكاة | سوق الخير | حساب ربع العشر، ثم توصيل الزكاة لمستحقيها فقط |
| ٤ | الصوم | واحة رمضان | السحور قبل الفجر، يوم صيام كامل (أعمال صالحة وتجنّب الطعام)، ثم الإفطار والدعاء |
| ٥ | الحج | وادي المناسك | الميقات والإحرام، الطواف ٧ أشواط، السعي، منى، عرفة، مزدلفة، رمي الجمرات |
| ٦–١١ | أركان الإيمان | حديقة الإيمان | تأمّل آيات الله والأسماء الحسنى، بوابات الملائكة، الكتب ورسلها، رموز قصص الأنبياء، الميزان، مواقف القدر |

كل مرحلة تنتهي باختبار قصير ونجوم (١–٣)، ويُضيء عمود أو مصباح في «ساحة الأركان». ويُحفظ التقدّم تلقائيًا في المتصفح، وتنتهي الرحلة بشهادة إتمام قابلة للطباعة. وفي الجزيرة ٢٠ «لؤلؤة معرفة» مخفية فيها أحاديث وفوائد.

ملاحظة: الشخصيات بلا ملامح وجه، ولا تُرسم صور الأنبياء ولا الملائكة؛ يُعبَّر عنهم بالأسماء والرموز والنور.

## للمطوّر
```bash
npm install
npm run build   # يُنتج dist/game.js و dist/game.css
npm run dev     # خادم تطوير على المنفذ 5173
```
الكود في `src/`: المحرك (`engine/`، `core/`)، العالم (`world/`)، اللعب والمراحل والمحتوى (`game/`)، والواجهة (`ui/`). كل النصوص التعليمية في `src/game/content.js`.
